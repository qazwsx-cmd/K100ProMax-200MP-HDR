# APK artifacts

These APKs are the v0.1.4 and v0.1.5 module builds supplied with the project materials.

| File | Version | Notes |
|---|---|---|
| `module-v0.1.4.apk` | 0.1.4 | Historical test build |
| `module-v0.1.5.apk` | 0.1.5 | Historical test build; its status journal recorded module entry and camera startup hooks |

There is no v0.1.6 APK in this repository. v0.1.6 is preserved as source and patch only; it has not been built with the complete target Android/libxposed toolchain or validated on the device.

Use only on the stated target environment, keep LSPosed scope limited to `com.android.camera`, and maintain a rollback path. Signing private keys and passwords are not included.
